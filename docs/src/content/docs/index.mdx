## Three lines of configuration

```js
// astro.config.mjs
starlightPydocs({
  packages: [{ name: 'mypkg', search: ['../src'] }],
});
```

One page per module at `/api/mypkg/`, a sidebar tree mirroring the package layout, plus
`symbols.json`, `objects.inv` and `llms.txt`.

## Coming from mkdocstrings

`starlight-pydocs` is the Starlight counterpart of
[mkdocstrings-python](https://mkdocstrings.github.io/python/) and keeps its conventions
where they make sense. Heading anchors are dotted object paths, `__all__` selects the
documented surface, `::: name` becomes `<Autodoc name="…" />`.
